# タスク時間自動割当（task_autofomat）

[![Version v7.4](https://img.shields.io/badge/version-v7.4-0f6a5a.svg)](docs/詳細設計書.md)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-blue.svg)](https://alikmpt8529.github.io/task_autofomat/)

限られた時間のなかで複数タスクを進めるための、ブラウザ完結型のスケジュール作成ツールです。

総時間を決め、タスクを細分化して時間を割り振り、開始時刻から各タスクの開始・終了時刻を自動計算します。現在時刻と残り時間もリアルタイムで表示します。

## 機能

- **総時間の設定** — 計画全体にかけてよい時間を時・分で決定
- **タスクの細分化と時間割当** — タスク名と所要時間を登録・編集
- **優先度・締切** — 高/中/低と締切日を設定。締切超過は強調表示
- **優先度・締切で自動割当** — 締切が近い・優先度が高い順に並べ、総時間を重みで割り振る
- **開始時刻からの自動スケジューリング** — 順序どおりに開始・終了時刻を算出
- **表形式の一覧表示** — `# / タスク名 / 優先度 / 締切 / 所要 / 開始 / 終了 / 残り`
- **超過の可視化** — 累積が総時間を超えたタスク行を赤色表示
- **現在時刻の表示** — 画面右上で 1 秒ごとに更新
- **残り時間のリアルタイム更新** — 進行中タスクはカウントダウン、未開始・完了も表示
- **現在時刻の取得** — ワンクリックで開始時刻に現在時刻をセット
- **次へボタン** — タスク完了後に表示。押すと次のタスクへ進み、残りを現在時刻から再スケジュール
- **フォーカスモード** — ON中にタスク実行中は画面をタイマー＋進捗リングのみに切り替え（Esc / フォーカス解除で終了）
- **均等割当** — 総時間をタスク数で均等に割り振る補助機能

## 使い方

1. **総時間** を入力し「決定」
2. **開始時刻** を入力して「決定」（または「現在時刻を取得」）
3. **タスク** を追加し、必要なら所要時間を表内で調整
4. 一覧表で開始・終了・残り時間を確認

所要時間の合計が総時間を超えると、超過したタスク行が赤くなります。

## 起動方法

ビルド不要です。**ES モジュールを使うため、ローカルでは静的サーバー経由での起動を推奨**します（`file://` ではモジュール読み込みがブロックされる場合があります）。

### 方法 A: ローカルサーバー（推奨）

プロジェクト直下で:

```bash
python3 -m http.server 8765
```

ブラウザで [http://127.0.0.1:8765/](http://127.0.0.1:8765/) を開く。

他の例:

```bash
npx serve .
# または
npx http-server -p 8765
```

### 方法 B: 本番（GitHub Pages）

公開 URL から利用: https://alikmpt8529.github.io/task_autofomat/

## サーバー構成

本ツールに **API サーバーやデータベースなどのバックエンドはありません**。  
ブラウザ上で完結する静的 Web アプリで、配信に必要なのは静的ファイルのホスティングのみです。

| 項目 | 内容 |
|------|------|
| アプリ種別 | クライアントサイド完結（HTML / CSS / JavaScript） |
| ビルド | 不要 |
| バックエンド | なし（認証・API・DB なし） |
| 配信対象 | `index.html` / `styles.css` / `js/*.js`（および `docs/` 等の静的資産） |
| 本番ホスティング | **GitHub Pages** |
| 配信元ブランチ | `main` |
| 公開ディレクトリ | リポジトリルート `/` |
| 公開 URL | https://alikmpt8529.github.io/task_autofomat/ |
| ローカル開発 | `python3 -m http.server 8765` などの静的サーバー |

```
[ユーザーのブラウザ]
        │

        ▼
[GitHub Pages]
  └── main ブランチのルート
        ├── index.html
```

## ファイル構成

```
task_autofomat/
├── README.md
├── index.html          # 画面エントリ
├── styles.css          # スタイル
├── js/
│   ├── main.js         # 起動・イベント配線
│   ├── util.js         # 共通ユーティリティ
│   ├── time.js         # 時刻・分数の変換・整形
│   ├── allocation.js   # 均等割当・優先度/締切割当
│   ├── schedule.js     # スケジュール算出・進捗
│   ├── dom.js          # DOM 参照・トースト等
│   ├── focus.js        # フォーカスモード UI
│   └── render.js       # 一覧・サマリー描画
└── docs/
    └── 詳細設計書.md
```

### モジュール分担

| ファイル | 役割 |
|----------|------|
| `js/time.js` | 時刻パース、所要時間表示、タイマー表示 |
| `js/allocation.js` | 均等割当、優先度・締切の重み按分 |
| `js/schedule.js` | 開始/終了の連鎖計算、超過判定、進捗ステータス |
| `js/focus.js` | フォーカスオーバーレイと進捗リング |
| `js/render.js` | サマリー・表・進行パネルの描画 |
| `js/main.js` | 状態初期化とユーザー操作の配線 |
