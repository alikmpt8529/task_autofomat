## 1. 概要

### 1.1 目的

限られた時間内で複数タスクをこなすために、次の一連の操作を支援する。

1. タスク全体にかけてよい時間（総時間）を定める
2. タスクを細分化し、各タスクへ時間を割り振る
3. 開始時間を入力し、各タスクの開始・終了時間を自動更新する
4. 結果を表形式で一覧表示する

### 1.2 実行形態

本ツールは **Web アプリケーション** として提供する。ユーザーはブラウザでアクセスし、インストール不要で利用できる。

| 項目 | 内容 |
|------|------|
| 提供形態 | Web（クライアントサイド完結の静的サイト） |
| 実行環境 | デスクトップ / モバイルの Web ブラウザ |
| サーバー依存 | 初期版は API・認証サーバー不要（静的ファイルの配信のみ） |
| 起動方法 | ローカル: `index.html` を開く、または静的サーバーで配信 / 本番: 任意の静的ホスティング |

### 1.3 対象ユーザー

- 作業前にタイムボックスを組みたい個人
- 会議・勉強・制作など、開始時刻が決まっている一連の作業の計画者

### 1.4 スコープ

| 区分 | 内容 |
|------|------|
| 対象 | Web ブラウザ上での総時間設定、タスク細分化、時間割当、開始時刻からのスケジュール算出、表一覧 |
| 対象外（初期版） | ネイティブアプリ、ユーザー認証、クラウド同期、通知、カレンダー連携、多人共有 |

| F-01 | 総時間設定 | Must | タスク全体にかけてよい時間を設定する |
| F-02 | タスク細分化 | Must | タスクを複数のサブタスクに分割して登録・編集する |
| F-03 | 時間割当 | Must | 各タスクへ所要時間を割り振る（合計が総時間以内） |
| F-04 | 開始時刻入力と時刻更新 | Must | 開始時刻から各タスクの開始・終了時刻を算出・更新する |
| F-05 | 表形式一覧表示 | Must | タスク名・所要時間・開始・終了を表で表示する |
| F-06 | 割当検証 | Should | 割当合計と総時間の過不足を表示する |
| F-07 | 編集・並び替え | Should | タスクの修正、削除、順序変更 |
| F-08 | ローカル永続化 | Could | ブラウザ等への一時保存 |

### 2.2 機能詳細

#### F-01 総時間設定

**目的**  
計画全体の上限時間（総時間）を定める。

**入力**

| 項目 | 型 | 必須 | 制約 | 例 |
|------|----|------|------|-----|
| 総時間（時間） | number | ○（時または分のいずれか必須） | 0以上の整数 | `2` |
| 総時間（分） | number | ○ | 0〜59 の整数。時間と合わせて総分数 > 0 | `30` |

**内部表現**  
総時間は分数（`totalMinutes`）に正規化する。

```
totalMinutes = hours * 60 + minutes
```

**処理**

1. 入力値を検証する
2. `totalMinutes` を算出して保持する
3. 既存タスクの割当合計と比較し、超過時は警告を出す（F-06）

**出力**  
画面上に「総時間: H時間 M分（合計 N 分）」を表示する。

---

#### F-02 タスク細分化

**目的**  
大きな作業を実行単位に分割する。

**入力（タスク1件）**

| 項目 | 型 | 必須 | 制約 | 例 |
|------|----|------|------|-----|
| タスク名 | string | ○ | 1〜100文字、前後空白除去後に空でない | `資料作成` |
| 順序 | number | △ | 未指定時は末尾追加。1始まり | `1` |

**操作**

| 操作 | 説明 |
|------|------|
| 追加 | リスト末尾（または指定位置）にタスクを追加 |
| 編集 | タスク名・ID以外の表示項目を更新 |
| 削除 | タスクを除去し、後続タスクの順序と開始・終了を再計算 |
| 並び替え | 順序変更後、開始・終了を再計算（F-04） |

**出力**  
タスク一覧（未割当の場合は所要時間・開始・終了が空またはプレースホルダ）。

---

#### F-03 時間割当

**目的**  
各タスクにかける時間を割り当てる。

**入力**

| 項目 | 型 | 必須 | 制約 | 例 |
|------|----|------|------|-----|
| 所要時間（分） | number | ○ | 1以上の整数 | `45` |

**割当方式（初期版）**

| 方式 | 説明 | 初期採用 |
|------|------|----------|
| 手動割当 | ユーザーが各タスクに分数を入力 | ○ |
| 均等割当 | 総時間をタスク数で均等分割（端数は最後に寄せる） | △（補助） |
| 比率割当 | 重みに応じて按分 | ×（将来） |

**検証ルール**

```
allocatedSum = Σ task.durationMinutes
remaining = totalMinutes - allocatedSum
```

| 条件 | 扱い |
|------|------|
| `allocatedSum < totalMinutes` | 警告: 残り時間あり（未使用 `remaining` 分） |
| `allocatedSum === totalMinutes` | 正常 |
| `allocatedSum > totalMinutes` | エラー: 総時間超過。超過の原因となるタスク行を赤色表示（F-05 / F-06） |

**処理**

1. 各タスクの `durationMinutes` を更新
2. 割当合計と残り時間を再計算
3. 超過判定（累積）を行い、該当タスクに `isOverLimit` を付与
4. 開始時刻が設定済みなら F-04 を再実行

---

#### F-04 開始時刻入力と時刻更新

**目的**  
全体の開始時刻を起点に、順序どおり各タスクの開始・終了時刻を自動算出する。

**入力**

| 項目 | 型 | 必須 | 制約 | 例 |
|------|----|------|------|-----|
| 開始時刻 | time / datetime | ○ | 有効な時刻。初期は当日の時刻として扱う | `09:00` |

**算出アルゴリズム**

タスクは順序 `order` の昇順で処理する。

```
current = startDateTime

for task in tasks sorted by order:
  task.startAt = current
  task.endAt   = current + task.durationMinutes
  current      = task.endAt
```

**再計算トリガー**

次のいずれかが変化したら、全タスクの開始・終了を再計算する。

- 開始時刻の変更
- タスクの所要時間変更
- タスクの追加・削除
- タスクの並び替え

**日跨ぎ**  
終了時刻が 24:00 を超える場合は翌日の時刻として表示する（例: `翌日 01:15`）。実装上は日時型で保持し、表示層で整形する。

**出力**  
各タスクの `startAt` / `endAt` が更新され、表に反映される。

---

#### F-05 表形式一覧表示

**目的**  
計画結果を一目で把握できる表で提示する。

**表示列（初期）**

| 列 | フィールド | 表示例 | 備考 |
|----|------------|--------|------|
| # | order | `1` | 実行順 |
| タスク名 | name | `資料作成` | |
| 所要時間 | durationMinutes | `45分` | |
| 開始 | startAt | `09:00` | 未設定時は `-` |
| 終了 | endAt | `09:45` | 未設定時は `-` |

**サマリー行（表上部または下部）**

| 項目 | 内容 |
|------|------|
| 総時間 | `2時間30分` |
| 割当合計 | `2時間15分` |
| 残り | `15分` |
| 全体開始 | `09:00` |
| 全体終了 | 最終タスクの `endAt` |

**UI要件**

- デスクトップでは横スクロールなしで主要列が見えること
- モバイルでは横スクロールまたは列の優先表示を許容
- 未割当（残り時間あり）はサマリーで警告表示する
- **総時間超過時は、超過に該当するタスクの行全体を赤色で塗る**（後述 F-06）

---

#### F-06 割当検証（Should）

- 総時間未設定時: タスク追加は可能、時刻確定は開始時刻と所要時間が揃うまで保留
- リアルタイムで残り時間・超過を表示
- 超過時はサマリーをエラー表示する
- **超過時は該当タスク行を赤色表示する**（Must 相当の表示要件）

**超過タスクの判定（累積方式）**

実行順（`order` 昇順）に所要時間を累積し、累積値が総時間を超えた時点以降のタスクを超過扱いとする。

```
cumulative = 0
for task in tasks sorted by order:
  cumulative += task.durationMinutes
  task.isOverLimit = (cumulative > totalMinutes)
```

| 例（総時間 150分） | 所要 | 累積 | isOverLimit | 表示 |
|--------------------|------|------|-------------|------|
| A | 30 | 30 | false | 通常 |
| B | 75 | 105 | false | 通常 |
| C | 60 | 165 | true | **行を赤色** |

- 赤色表示の対象: 表の当該行全体（背景色）
- 推奨スタイル例: 背景 `#FEE2E2`、文字 `#991B1B`（コントラスト確保）。実装時にテーマ変数へ切り出してよい
- 色のみに依存しないよう、サマリー文言「割当合計が総時間を超えています」も併記する
- `allocatedSum <= totalMinutes` に戻った時点で、全行の赤色を解除する

---

#### F-07 編集・並び替え（Should）

- インライン編集または編集フォーム
- ドラッグ＆ドロップまたは上下ボタンで順序変更
- 変更後は F-04 を自動実行

---

#### F-08 ローカル永続化（Could）

- `localStorage` 等に JSON で保存
- キー例: `task_autofomat.plan.v1`
- 起動時に復元、クリア操作を用意

## 5. 処理設計

### 5.1 ユースケースフロー

```
[開始]
  → 総時間を入力 (F-01)
  → タスクを追加し細分化 (F-02)
  → 各タスクに時間を割当 (F-03)
  → （任意）均等割当で初期値を埋める
  → 開始時刻を入力 (F-04)
  → 各タスクの開始・終了が更新される
  → 表で一覧確認 (F-05)
  → 必要なら編集・並び替え → 再計算
[終了]
```

### 5.2 コア関数仕様

#### `toTotalMinutes(hours, minutes) -> number`

- 前置条件: hours ≥ 0, 0 ≤ minutes ≤ 59
- 後置条件: 戻り値 ≥ 0

#### `allocateEvenly(totalMinutes, taskCount) -> number[]`

- 各要素は `floor(totalMinutes / taskCount)`
- 余り `totalMinutes % taskCount` は先頭または末尾タスクに1分ずつ配分（方針を実装時に固定。推奨: 先頭から配分）

#### `recalculateSchedule(startAt, tasks) -> tasks`

1. `tasks` を `order` でソート
2. `cursor = startAt`
3. 各タスクについて `startAt = cursor`, `endAt = cursor + duration`, `cursor = endAt`
4. 更新済み `tasks` を返す

#### `validateAllocation(totalMinutes, tasks) -> ValidationResult`

```
{
  allocatedSum: number,
  remaining: number,
  status: "ok" | "under" | "over"
}
```

### 5.3 状態遷移（割当ステータス）

```
[未設定] --総時間入力--> [総時間設定済]
[総時間設定済] --タスク+所要時間--> [割当中]
[割当中] --開始時刻入力--> [スケジュール確定]
任意状態 --編集--> 再検証・必要なら再計算
```

## 7. 技術方針（Web 実行）

Web ブラウザで完結して動作する構成とする。

| 層 | 採用 |
|----|------|
| 実行基盤 | Web ブラウザ（静的 HTML / CSS / JavaScript） |
| UI | 単一ページ（`index.html` + `styles.css` + `app.js`） |
| 状態管理 | クライアントメモリ上の Plan 状態（再描画で同期） |

| ホスティング | GitHub Pages / Netlify / Cloudflare Pages / 任意の静的サーバー |

### 7.1 ディレクトリ構成

```
task_autofomat/
  index.html       # エントリ（ブラウザで開く）
  styles.css       # スタイル（超過行の赤色含む）

```

### 7.2 ローカル実行手順

1. リポジトリ直下で静的サーバーを起動する（例: `npx serve .` / `python3 -m http.server`）
2. ブラウザで表示された URL を開く
3. または `index.html` をブラウザで直接開く（ファイルプロトコルでも動作する構成とする）

### 7.3 本番配信

静的ファイル（`index.html` / `styles.css` / `app.js`）をホスティングし、HTTPS で公開する。サーバーサイド処理は不要。

## 8. エラーハンドリング

| 種別 | 方針 |
|------|------|
| 入力不正 | フィールド横またはフォーム上部にメッセージ。計算は行わない |
| 割当超過 | サマリーで警告表示し、超過該当タスク行を赤色で塗る。時刻計算は実行してよい（計画の可視化を優先） |
| 開始時刻なし | 所要時間までは表示、開始・終了列は `-` |
| 永続化失敗 | トースト等で通知し、メモリ上の状態は維持 |

## 9. 受け入れ条件（要点対応）

| # | 要点 | 受け入れ条件 |
|---|------|----------------|
| 1 | 総時間を定める | 時・分入力で総分数が保持・表示される |
| 2 | 細分化と時間割当 | 複数タスクを登録でき、各所要時間を設定できる。合計と総時間の差分が見える。超過時は該当タスク行が赤色になる |
| 3 | 開始時間入力と更新 | 開始時刻変更・所要変更・並替のたびに各タスクの開始・終了が連番で更新される |
| 4 | 表形式一覧 | `# / タスク名 / 所要 / 開始 / 終了` が一覧表で表示され、全体終了時刻が分かる |

### 9.1 受け入れシナリオ例

**前提**: 総時間 150分、開始 09:00  
**タスク**: A 30分 / B 75分 / C 45分  

**期待される表**

| # | タスク | 所要 | 開始 | 終了 |
|---|--------|------|------|------|
| 1 | A | 30分 | 09:00 | 09:30 |
| 2 | B | 75分 | 09:30 | 10:45 |
| 3 | C | 45分 | 10:45 | 11:30 |

- 割当合計 = 150分、残り = 0
- 全体終了 = 11:30

B を 60分に変更した場合、C の開始は 10:30、終了は 11:15 に更新されること。

**超過表示シナリオ**

**前提**: 総時間 150分  
**タスク**: A 30分 / B 75分 / C 60分（累積 165分）

| # | タスク | 所要 | 累積 | 行の表示 |
|---|--------|------|------|----------|
| 1 | A | 30分 | 30 | 通常 |
